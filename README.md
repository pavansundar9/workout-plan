# Workout Plan

A lightweight Vite + React app for the `gate2027-workout.jsx` plan.

## Run locally

```powershell
cd c:\Users\pende\VSCODE\workout-plan
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build for production

```powershell
npm run build
npm run preview
```

## Notes

- The app uses `localStorage` for session persistence.
- If you deploy to GitHub Pages, set `base` in `vite.config.js` to the repository name path.
